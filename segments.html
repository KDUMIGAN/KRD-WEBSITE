Rider profiles

CdA guide: hoods ≈ 0.32–0.36, drops ≈ 0.28–0.30, TT position ≈ 0.22–0.25. Crr: good road tyres on chip-seal ≈ 0.005, smooth hotmix ≈ 0.004. Power is your best effort for that duration. The model interpolates between them for each segment's predicted time.

Model

Open-Meteo wind is at 10 m. At rider height it's lower, so it's scaled by the exposure factor (0.75 suits suburban roads; use 0.9 for open cane-field roads). Gust weighting blends the gust toward the sustained speed. Calibration: if predictions are faster than your real PRs on calm days, lower it.

Traffic

Traffic is a manual rating per segment, set from each segment's "Rate & details" panel. Peak-hour weighting is off. Live traffic provider: none (slot reserved in the code at liveTrafficRating()).

Data

Export includes profiles, settings, traffic ratings, KOM holders and the ignore list. It never includes Strava credentials or Strava segment data, so it's safe to send to your mate. Import merges ratings into yours.

Strava connection

  1. Create an API app at strava.com/settings/api (callback domain localhost).
  2. Copy the Client ID, Client Secret and Refresh Token from that page into the fields below.
  3. Press Save & test. The page refreshes access tokens itself from then on.
Each rider uses their own Strava API app and enters their own details on their own phone.

Notes

Credentials and data stay in this browser only (local storage). Strava's API terms restrict this data to personal use, so don't publish screenshots of the lists or share your cached data. Wind comes from Open-Meteo (free, no key). The map uses OpenStreetMap.
