Rider profiles

CdA guide: hoods ≈ 0.32–0.36, drops ≈ 0.28–0.30, TT position ≈ 0.22–0.25. Crr: good road tyres on chip-seal ≈ 0.005, smooth hotmix ≈ 0.004. Power is your best effort for that duration. The model interpolates between them for each segment's predicted time.

Model

Open-Meteo wind is at 10 m. At rider height it's lower, so it's scaled by the exposure factor (0.75 suits suburban roads; use 0.9 for open cane-field roads). Gust weighting blends the gust toward the sustained speed. Calibration: if predictions are faster than your real PRs on calm days, lower it.

Import a KOM list (yours or a mate's)

On strava.com, open their profile's KOMs list, select the whole table, copy it and paste it here. You can paste several pages at once. Segments are matched by name and distance, including ones you import later.

Area & ride import

The area sets where the wind forecast is taken from and filters segments imported from your rides. Starred and pasted segments are always kept. Each ride costs one Strava call and is only read once.

API budget

Traffic

Traffic is a manual rating per segment, set from each segment's "Rate & details" panel. Peak-hour weighting is off. Live traffic provider: none (slot reserved in the code at liveTrafficRating()).

Data

Full backup saves everything: segments, KOM times, PRs, ratings, KOM lists, ignore list, rider profiles, settings, area, rides already read and your Client ID/Secret. It leaves out your Strava tokens, so after importing on another device just tap Authorise with Strava once. Keep this file to yourself. It holds your Client Secret and Strava data.

Share settings is for your mate. It holds profiles, settings, traffic ratings, KOM holders, KOM lists and the ignore list, with no Strava data and no credentials.

Importing merges into this device: newer KOM times win, and ratings and lists are combined.

Strava connection

  1. Create an API app at strava.com/settings/api (callback domain localhost).
  2. Enter your Client ID and Client Secret below.
  3. Tap Authorise with Strava and approve. The page it lands on will fail to load. That's expected.
  4. Copy the whole address from the address bar, paste it in the box below and tap Connect.
The page refreshes tokens itself from then on. Each rider uses their own Strava API app on their own phone.
